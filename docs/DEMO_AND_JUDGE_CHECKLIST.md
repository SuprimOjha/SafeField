- [ ] Start backend and frontend from clean installs.
- [ ] Run the complete backend test suite.
- [ ] Check health and field-assessment endpoints for Biratnagar.
- [ ] Confirm every source displays observation date, fetch timestamp, status and caveat.
- [ ] Confirm null/unavailable inputs produce LOCAL REVIEW NEEDED, not zero or a favorable signal.
- [ ] Confirm POWER's latest observation date and latency are visible.
- [ ] Confirm GWETTOP/GWETROOT are labelled modelled wetness proxies.
- [ ] Confirm SoilGrids is labelled predicted 250 m, 0–5 cm topsoil.
- [ ] Confirm Open-Elevation is not mislabeled NASADEM.
- [ ] Confirm GPM IMERG and SMAP are described as not connected.
- [ ] Test GPS, district selection, one-tap map selection and optional polygon drawing on a real phone.
- [ ] Test map provider attribution and Esri usage terms before public launch.
- [ ] Record a real farmer interview only with informed consent; do not stage or fabricate testimonials.
- [ ] Show limitations and the validation plan in the presentation.
