# Mobile usability requirements

- A farmer must be able to get a first location-based assessment from a single map tap, GPS or district selection.
- Drawing a field polygon is optional and should refine the location, not block the first result.
- Controls must be touch-friendly and readable on small Android screens.
- GPS denial must not block manual location selection.
- Show loading, offline, cached and unavailable states distinctly.
- Do not show stale or unavailable source values as current measurements.
- Test with real devices and low-bandwidth connections before claiming mobile readiness.
